# Verification Checklist

Use this before a future agent claims a wave is complete.

## Repo

- `pnpm install` completes.
- `pnpm lint` completes.
- `pnpm typecheck` completes.
- `pnpm build` completes for each app.
- README explains setup for a non-developer.
- Vercel root directories are documented.

## Frontend

- Desktop screenshot inspected.
- Mobile screenshot inspected.
- No overlapping text or controls.
- Keyboard focus is visible.
- Reduced motion path exists for animated experiences.
- Images have dimensions and useful alt text.
- Metadata and OG image exist.
- Lighthouse or equivalent pass is recorded when feasible.

## Odissi Sydney

- All live-site pages have been captured.
- Claims are traceable to source or family confirmation.
- Cultural references are respectful and specific.
- Contact paths work.
- The site feels warm, rigorous, and dignified.

## Caldera

- Audio does not autoplay with sound before consent.
- Player works on mobile and desktop.
- 3D/canvas visual is nonblank and performant.
- Reduced-motion mode avoids heavy animation.
- Community safety information is findable before event commitment.
- Event links and dates are accurate.
